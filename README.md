# Personal CV Website

## What
A simple, clean HTML-based CV/resume website showcasing my professional profile, skills, education, and work experience. The site features a responsive design with a modern, minimalist aesthetic.

## Why
- **Professional Online Presence**: Having a web-based CV makes it easily shareable and accessible
- **Modern Approach**: Demonstrates web development skills while presenting professional information
- **Responsive Design**: Works seamlessly across desktop, tablet, and mobile devices
- **Print-Friendly**: Optimized CSS for clean printing when needed

## How
The website is built using:
- **HTML5** for semantic structure
- **CSS3** for styling and responsive design
- **Embedded CSS** for easy deployment and maintenance
- **Semantic HTML** for accessibility and SEO

### Features
- Clean, professional layout with green and blue accent colors
- Responsive design that adapts to different screen sizes
- Print-optimized styles for physical copies
- Semantic HTML structure for better accessibility
- Fast loading with no external dependencies

### Usage
Simply open `index.html` in any modern web browser to view the CV. The site works offline and requires no server setup.
